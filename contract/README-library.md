# Library README (postcard)

Root `README.md` is not a CMS. Shape:

```markdown
# <repo>

One or two sentences of denotation.

See [docs/](docs/).

## License
…block that matches LICENSE files on disk…

---
…QuantX footer…
```

Do not add a second `See docs/` line if it is already present. Install, usage, and API tables live in `docs/`.
