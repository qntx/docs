---
title: Callouts
description: Info, warn, error, success, and idea callouts, with and without titles.
---

Default MDX includes `<Callout>`. All five types must render.

<Callout>Untitled info. Default type.</Callout>

<Callout title="Info" type="info">
  Use for a fact the reader should not miss.
</Callout>

<Callout title="Warning" type="warn">
  Use for a reversible mistake (wrong env, wrong host).
</Callout>

<Callout title="Error" type="error">
  Use for a hard failure. Do not continue until this is fixed.
</Callout>

<Callout title="Success" type="success">
  The health check returned 200.
</Callout>

<Callout title="Idea" type="idea">
  Prefer Copy Markdown over pasting rendered HTML into an agent.
</Callout>
